# 🎯 FreeAI v2.0 - Quick Reference Card

## 📱 Usage

### Basic Chat
1. Type question in input field
2. Press **Enter** or click send button (✈️)
3. AI responds in real-time

### Image Upload & Analysis
1. Click **"Upload Image"** button
2. Select image from computer
3. *(Optional)* Type a question about image
4. Click send
5. AI analyzes image instantly

### Switch AI Models
1. Click any model button at top:
   - **GPT-5 Nano** (fastest)
   - **Claude Sonnet 4.5** (best quality)
   - **DeepSeek v3.2** (shows reasoning)
   - **DeepSeek Reasoner** (deep analysis)
   - **Gemini 2.5 Flash** (great with images)
   - **Grok-4 Fast** (fun & creative)
2. Button highlights when selected
3. Next message uses selected model

### Clear Chat
- Click trash can button (🗑️) to delete all messages

## 🖼️ Image Upload

**Supported Formats:**
✅ JPEG/JPG, PNG, GIF, WebP, BMP, TIFF

**Limits:**
- Max file size: 32 MB
- Multiple images: Upload one at a time
- Max quality: Full HD (recommended)

**How it works:**
1. Image → ImgBB hosting → URL generated
2. URL sent to AI → Image analyzed
3. Response displayed in chat

## 🐛 Quick Troubleshooting

### Image upload not working?
1. Check file size (< 32 MB)
2. Try JPG format
3. Refresh page (Ctrl+R)
4. Try different image

### Model not responding?
1. Try different model
2. Refresh page (Ctrl+R)
3. Check internet connection
4. Wait 10 seconds and retry

### UI looks broken?
1. Refresh page (Ctrl+R)
2. Hard refresh (Ctrl+Shift+R)
3. Zoom reset: Ctrl+0
4. Try different browser

### Still stuck?
→ Read [TROUBLESHOOTING.md](TROUBLESHOOTING.md)
