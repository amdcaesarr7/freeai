# Quick Start Guide - FreeAI v2.0

## 🚀 Getting Started in 30 Seconds

### 1. **Open the Application**
- Navigate to `freeai/index.html` in your browser
- You'll see the beautiful AI chat interface

### 2. **Select an AI Model**
Click any of the model buttons at the top:
- **GPT-5 Nano** ← Default (Fastest)
- **Claude Sonnet 4.5** ← Best for complex questions
- **DeepSeek v3.2** ← Shows reasoning
- **DeepSeek Reasoner** ← Deep analysis
- **Gemini 2.5 Flash** ← Great for images
- **Grok-4 Fast** ← Fun & creative

### 3. **Ask a Question**
Type in the input box and press **Enter** or click the send button.

### 4. **Watch the Response Stream**
See the AI thinking in real-time!

---

## 📸 Image Upload Feature

### How to Upload & Analyze:
1. Click **"Upload Image"** button
2. Select an image file from your computer
3. *(Optional)* Type a question about the image
4. Click **Send**
5. The AI will analyze your image!

### Supported Formats:
- ✅ JPEG / JPG
- ✅ PNG
- ✅ GIF
- ✅ WebP
- ✅ BMP
- ✅ TIFF

### Size Limits:
- Max 32 MB per image (ImgBB free tier)
- Larger files will be rejected

## 🐛 Common Issues & Solutions

### **"Image upload failed"**
- Check file size (< 32 MB)
- Try a different image format
- Check internet connection
- Refresh and try again

### **"Model not responding"**
- Try a different model
- Refresh the page
- Check your internet connection
- Check browser console (F12)

### **"Response is slow"**
- GPT-5 Nano is the fastest
- Shorter prompts load faster
- Streaming models take time to start
- Try a different model
